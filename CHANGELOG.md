# Changelog

Changes are recorded for source snapshots. An entry here does not imply an App Store release or a signed downloadable build.

## Unreleased

### Initial public source snapshot

- Native iPhone/iPad app for finding and replacing pending on-chain Bitcoin payments.
- Cancel and Speed up review modes, fee selection, device-owner authentication, signing checks, and transaction-ID verification.
- BIP39, WIF, hex, mini-key, and supported extended-private-key import; exact BIP39 passphrase handling.
- Reusable camera/photo scanner with supported multipart QR decoding.
- BIP44/49/84/86 discovery, batched Electrum history/UTXO queries, configurable accounts and custom paths.
- Server settings, connection tests, public confirmation tracking, and upstream license notices.
- Native navigation/back gestures, sheets, bottom toolbars, adaptive layout, and Takeback artwork.
- Build instructions, architecture, privacy/security documentation, contribution templates, and automated publication checks.
